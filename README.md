# brain-oscillation
# Effects of neural noise on gamma-band activity and variability in spiking excitation-inhibition networks


##### The Problem & Solution  #####

Cortical circuits rely on coordinated interactions between excitatory and inhibitory neurons to generate rhythmic electrical activity, including gamma-band oscillations (30–90 Hz). In real biological networks, continuous stochastic fluctuations (neural noise) can disrupt spike timing and alter population dynamics.

These simulations use Python and Brian 2 spiking neural networks to test how increasing noise intensity ($\sigma$) and varying synaptic connection strengths change neuronal firing patterns, gamma-band spectral activity, binned population spike-count variability, and firing-rate variability in simplified excitation-inhibition networks.
